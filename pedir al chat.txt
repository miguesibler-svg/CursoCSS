# Proyecto web básico: HTML y CSS

## Objetivo del proyecto

Desarrolla un proyecto web básico compuesto únicamente por **dos archivos separados**:

* Un archivo HTML.
* Un archivo CSS ubicado en la ruta `css/ejercicio.css`.

El archivo HTML debe enlazar correctamente la hoja de estilos mediante la siguiente ruta:

css/ejercicio.css

## Requisitos generales

* Utiliza una estructura HTML semántica, correcta y coherente.
* No utilices JavaScript.
* El código debe estar correctamente indentado, organizado y estructurado.
* Tanto el HTML como el CSS deben ser claros, ordenados y fáciles de leer y comprender.
* El diseño debe ser simple, limpio y funcional.
* El archivo HTML debe incluir **todas las etiquetas y elementos solicitados**, sin agregar etiquetas HTML adicionales.
* El archivo CSS debe incluir **todos los selectores, pseudoclases y propiedades CSS solicitados**, sin agregar propiedades CSS adicionales.

Todas las etiquetas y elementos solicitados deben utilizarse de manera **correcta, coherente y funcional** dentro de la estructura de la página.

El contenido debe estar relacionado con el tema seleccionado y todos los elementos deben integrarse de forma natural dentro del sitio web. Evita utilizar etiquetas o elementos únicamente para cumplir con el requisito; cada uno debe tener una función coherente dentro de la página.

## Tema de la página

* Una cafetería.

El resultado final debe ser un proyecto web completo compuesto únicamente por:

1. Un archivo HTML.
2. Un archivo CSS ubicado en css/ejercicio.css.

El código debe ser **claro, ordenado, correctamente estructurado y fácil de comprender para una persona que está aprendiendo HTML y CSS desde cero**.
