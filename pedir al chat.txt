Genera un proyecto web básico compuesto por dos archivos separados:

un HTML y un css

El archivo html debe enlazar correctamente el archivo styles.css. No utilices JavaScript, bibliotecas externas ni frameworks.

El objetivo es crear una página web realista, sencilla y bien organizada, pensada para que un estudiante de nivel principiante practique HTML y CSS.

## Requisitos generales

* Utiliza una estructura semántica correcta.
* El código debe estar correctamente indentado y organizado.
* El HTML y el CSS deben ser fáciles de leer y comprender.
* El diseño debe ser simple, limpio y funcional.
* El CSS debe ser exclusivamente de nivel principiante, utilizando únicamente propiedades básicas como:

  * color
  * background-color
  * font-family
  * font-size
  * text-align
  * width
  * height
  * margin
  * padding
  * border
  * border-radius
  * display
* No utilices Flexbox, CSS Grid, `position`, animaciones, transiciones, variables CSS ni técnicas avanzadas.

## Tema de la página

Selecciona un tema realista (por ejemplo, una cafetería, una biblioteca, una tienda de mascotas, un restaurante, una papelería o un gimnasio). Todo el contenido debe estar relacionado con ese tema para que el sitio tenga coherencia.

## Objetivo

El resultado debe ser un proyecto completo formado únicamente por un archivo html y css, donde se utilicen correctamente todas las etiquetas solicitadas y un CSS básico. El código debe ser claro, ordenado y fácil de entender para una persona que está aprendiendo HTML y CSS desde cero.
