Proyecto web básico: HTML y CSS

Genera un proyecto web básico compuesto únicamente por dos archivos separados:

Un archivo HTML.
Un archivo CSS ubicado en css/ejercicio.css.

El archivo HTML debe enlazar correctamente el archivo CSS mediante la ruta css/ejercicio.css.

Requisitos generales
* Utiliza una estructura HTML semántica y correcta.
* No utilices JavaScript.
* El código debe estar correctamente indentado, organizado y estructurado.
* El HTML y el CSS deben ser fáciles de leer y comprender.
* El diseño debe ser simple, limpio y funcional.
* El archivo HTML debe incluir todas las etiquetas solicitadas y no se deben agregar etiquetas HTML adicionales.
* El archivo CSS debe incluir todos los selectores, pseudoclases y propiedades CSS solicitadas y no se deben agregar propiedades CSS adicionales.
* Requisitos del archivo HTML

Genera un archivo HTML que contenga y utilice correctamente todas las siguientes etiquetas y elementos: 

header, nav, section, article, div, footer, h1, h2, h3, h4, h5, h6, p, strong, em, b, i, u, span, br, hr, a, img, video, audio, ol, ul, li, dl, dt, dd, table(colspan, rowspan), caption, tr, th, td, form, fieldset, legend, label, input(text (placeholder), number, email, password, date, file, checkbox, radio), textarea(readonly), select(multiple), optgroup, option(selected, disabled), button(reset, submit).

Todas las etiquetas y elementos solicitados deben utilizarse de manera correcta y coherente dentro de la estructura de la página. Los elementos deben estar relacionados con el tema seleccionado y deben integrarse de forma natural en el contenido.

Requisitos del archivo CSS

Genera un archivo CSS que contenga y utilice correctamente los siguientes selectores, conceptos y propiedades: 

selectores, clases, selector id, pseudoclases, color, font-family, font-size, text-align, background-color, background-image(url("../img/img.jpg")), background-repeat(repeat, no-repeat), background-size, background-attachment, background-position, border-style(solid, groove, dashed, dotted, double), border-radius, border-width, border-color, hover.

La pseudoclase :hover debe utilizarse correctamente para generar un cambio visual al pasar el cursor sobre elementos interactivos, como enlaces o botones.

No se deben agregar propiedades CSS adicionales que no estén incluidas en la lista solicitada.

## Tema de la página

Selecciona un tema realista (por ejemplo, una cafetería, una biblioteca, una tienda de mascotas, un restaurante, una papelería o un gimnasio). Todo el contenido debe estar relacionado con ese tema para que el sitio tenga coherencia.

## Objetivo

El resultado debe ser un proyecto completo formado únicamente por un archivo html y css, donde se utilicen correctamente todas las etiquetas solicitadas y un CSS básico. El código debe ser claro, ordenado y fácil de entender para una persona que está aprendiendo HTML y CSS desde cero.
